# SysRadio

A small internet radio player for Windows and macOS, by SysSteve. Search stations from the free
[radio-browser.info](https://www.radio-browser.info) directory, keep favourites, see what is
playing, control it from the tray or with the media keys. No ads, no tracking.

Built with Tauri 2 (Rust) and Svelte 5. Developer notes: [CLAUDE.md](CLAUDE.md),
[docs/architektur.md](docs/architektur.md), [docs/decisions.md](docs/decisions.md).

```bash
pnpm install
pnpm dev            # UI in the browser with sample stations
pnpm check          # format, types, unit tests
```
